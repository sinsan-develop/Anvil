# P02 실행기 위협과 위험 관리

상태: **설계 위험·필수 검증 상세 / 구현·보안 검증 미실행**. Main 어울, 2026-10-16. 설계 r8 본문 §12.1.1의 위협과 계획 r7 §2.3 위험 등록부의 상세 조회본이다. 인증/키/암호화 제품·정책 수치의 실제 선택과 배포 승인을 대신하지 않는다. FN01/06/08/11/13/15/16의 상세 계약과 검수로 소비한다.

## 1. 보호 대상과 신뢰 경계

보호 대상은 사용자 소스·PC 실행 권한·Anvil 원문/결정·인증정보·승인/제어권·실행 증거다. 경계는 브라우저↔서버, 서버↔Windows 실행기, 실행기↔Agent/자식 프로세스, 허가 root↔실제 파일/WSL 대상, 원문/spool↔조회/외부 전송/백업이다. 서버가 인증됐다는 사실만으로 모든 명령을 안전하게 보지 않는다.

## 3. 적용 순서와 미충족 처리

기술 독립 문서/화면·저장 기능은 외부 Agent 미확인만으로 전부 중단하지 않는다. 하지만 실제 PC 변경은 인증·허가·단독 제어/중복·경로·안전 회수의 필수 조건을 충족한 뒤에만 허용한다. 위험별 증거가 없으면 미검증으로 남기고 실제 권한/비용/자료 영향이 필요한 결정만 사용자에게 요청한다. go/no-go는 해당 실행 경로의 판단이며 프로젝트 전체 범위 축소 승인과 다르다.
