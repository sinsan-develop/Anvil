# Anvil v3 설계 기능과 업무 검증 추적

2026-10-16 Main 어울. 설계 r8 본문 §13.1.1과 계획 r7/업무 카드의 파생 조회표다. 설계/계획의 본문 반영을 이 표로 대신하지 않는다. 다대다 관계이며 ID 1:1을 주장하지 않는다. 표 존재는 구현/시험 완료가 아니다. 실제 코드/시험/증거의 역참조는 각 업무 결과가 공급한다.
