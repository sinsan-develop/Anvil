# P01 클릭형 설계 검토 시안

진입점: `index.html`. 파일을 브라우저로 직접 열거나, 이번 검토용 loopback 미리보기의 링크로 연다. 제품 서비스가 아니라 설계용 HTML이다. 시작 화면은 프로젝트 목록이며 왼쪽 방법론 메뉴에서 기본3종을 검토한다.

## 이번에 눌러볼 수 있는 것

1. 방법론 → 구조적/객체지향/애자일 상세 보기 → 단계 선택, 문서·검수 구성 확인.
2. 기본본 사용→프로젝트 만들기→목적/소스→방법론/자료→도구/환경→시작 기준 확인의 4단계→시안 생성→총괄 기본 작업 화면. 탭에 중간 초안을 보관·다시 불러올 수 있다. 미확인 환경은 ‘준비 필요’이며 생성이 실행을 시작하지 않는다.
3. 기본본 복사·수정 또는 빈 방법론 직접 정의→노드 추가/이름·목적·입력·산출·문서·완료 조건 편집→노드 반영→시작/종료·순차/분기/재작업 연결→연결 검사→프로젝트 선택. 노드 삭제는 연결 영향 확인 후 처리. 시스템 원본은 바뀌지 않는다.
4. 총괄/책임자 전환·대화 예시 추가·건별/자동 표시 전환.
5. 승인·문제 → 한 예시 요청 결정. 중복 결정 차단, 실제 승인은 아님.
6. 도구 이전 → 정지 미확인일 때 재개 차단 → 정지 확인만으로도 재개 차단 → 이해 확인까지 하면 시안 재개 활성.
7. 상단 상태 검토: 정상/로딩/빈/조회오류/조회전용/연결단절/로그인만료/버전충돌. 빈 목록에서 새 프로젝트 생성까지 진행할 수 있다.
8. 문서·설계 추적 → 텍스트와 자료 이름 입력 → 현재 문서와 비교 → 탭 문서에 반영. 비교만으로 버전이 바뀌지 않으며, 반영 후 이전 원문을 펼쳐볼 수 있다. 버전 충돌 예시에서는 덮어쓰기를 차단한다.
9. 작업 권한 인계 → 요청 → 기존 담당의 안전 요약 → 다음 담당 수락. 요청만으로 제어권을 바꾸지 않는다. 설정·보조 조회 → 손상/누락 백업은 검증 실패·영향 확인 차단, 정상 예시는 영향 확인까지만 제공한다.
10. 공간형 흐름도 → 노드 선택 → 복사본에서 방향 버튼으로 위치 이동·확대/축소. 선은 연결 순서이며 위치를 옮겨도 연결은 바뀌지 않는다. 연결 표·오류 검사도 유지한다.
11. 방법론/문서 화면의 공식 양식8종 → 필수 목차/작성 규칙 → 선택 노드 필수 양식 연결 → LLM 작성 임무 보기. 실제 전송하지 않는다. 빈 초안은 검사에서 부족으로 표시하며, 수동 입력한 본문과 작성 단계/출처/작성 주체를 탭에 보관하면 ‘검토 대기’로 본문을 조회한다. 양식 간 전환 때 작성 중 본문을 탭에 유지한다.
12. 로컬 .md/.txt 선택→탭 읽기→줄별 비교→별도 반영. 업로드·문서 속 명령 실행 없음. 초기화·빈 양식 교체는 입력이 있으면 재확인한다. 역할별 미전송 지시는 만료/화면 이동에도 탭 안에서 유지한다.
13. 이전 시 대상 필수 기능·기록/공백·이해·확인 주체도 대조한다. 부족 시 재개 차단. 설계 변경은 승인 뒤 계획 개정까지 확인해야 영향 업무 재개 가능. 인수 뒤 이전 클라이언트는 조회 전용 예시로 전환한다.
14. 지식 검색·정정/사용제외와 이전 원문/이력 조회, 공유 내용·대상 사전 확인. 도구/환경/권한 탭은 설정 초안만 보관하며 연결 성공이나 권한 확대로 표시하지 않는다.

## 한계·미완료 — 사용자 검토 전

- 모든 내용은 예시이며 실제 프로젝트/DB 저장·외부 호출·코딩 Agent·승인·백업·원격 접속 없음. 새로고침하면 메모리 상태 초기화.
- 기본3종과 [상세안](../../기본방법론_상세검토안.md)·1차 화면 방향은 [사용자 승인 기록](../../../04_test_reports/AV3/P01/REVIEW-01.md)에 보존했다. 이후 보완한 편집 동작의 검토는 별개다.
- P01 주요 화면·행동·차단 상태를 [2차 검토 묶음](../../../04_test_reports/AV3/P01/REVIEW-02.md)에 정리했다. 사용자 최종 검토는 아직 없다. 실제 제품 기능과 모든 기술 선택을 완성한 것이 아니다.
- 사용자 노드/연결 편집과 필수값·시작/종료·도달·순환·분기/합류·중복 연결 검사를 유지하며 연결선·조건/재작업 표시·노드 방향 이동·배율을 보완했다. 포인터 드래그/자동 정렬은 미제공이다. 공간형 보기에서도 연결을 추가/제거하는 편집은 아래 연결 표/폼을 사용한다.
- [공식 양식 상세 초안](../../공식산출물_양식정의.md)은 2026-10-15 신산님의 ‘P01 시안·양식 승인’으로 후속 구현 상세 기준이 됐다. 정확한 승인 범위·hash는 [REVIEW-02](../../../04_test_reports/AV3/P01/REVIEW-02.md)를 따른다. 양식 필수항목 검사는 형식만 검사한다. 내용의 사실성·실제 증거·시안 첨부 렌더·LLM 작성/결과 회수·영속 저장/권한 조회는 미구현이다.
- 선택한 사용자 절차는 프로젝트·주 작업 화면으로 이어지고 단계 선택 시 해당 단계 입력/산출/완료 조건을 표시한다. 모든 책임/자료 상태 연결·안전 중지·상세 인수/복구는 추가 구체화 대상이다.
- 시안 원본 필드에 입력해도 시스템 자료는 변경되지 않으며 복사본만 편집한다. 노드 속성·작성 본문·미전송 지시·주요 설정/정정 입력은 탭 초안에 보존한다. 새 정의/복사·보관 초안 복원·빈 양식 교체·초기화는 재확인한다. 브라우저 이탈 경고를 요청하지만 실제 팝업의 브라우저별 검증은 미실행이다. 서버 저장/영속 복원이 아니다.
- 주 작업 화면의 1920×1080·1440×900 가로 넘침 없음, 430×844에서 절차/자료 숨김과 하단 탭 전환을 실제 브라우저에서 확인했다. 전체14화면의 모든 규격·실기기 검증은 미실행이다. 임시 viewport 설정은 검사 뒤 원복했다.
- 글자/위치/행동에 관한 의견은 대화로 알려주면 근거·수정 이력으로 반영한다. 화면 클릭을 사람의 정식 설계 승인으로 수집하지 않는다.

## 확인 기록

`node verify.cjs`: 시안 JS 구문·14경로 렌더·6상태·정지/이해 조건·조회권한·일회결정·문자escape·외부 API 없음, 복사본 격리·빈 정의·순환/조건 누락/도달/분기/합류/중복연결 검사와 편집본 전환 확인을 검증한다. 실제 브라우저/제품 시험과 다르다.

최신 검사에서는 위 기존 계약에 14경로×8상태 렌더·파일 읽기 성공/지원불가 형식/안전 크기·줄별 비교·만료 입력·교체/초기화·대상 기능/확인 주체·변경 계획 개정·인계 후 이전 클라이언트 차단을 추가했다. 최종 exit0. 파일 text() 자체의 예외 처리 코드는 있으나 강제 읽기 실패 시험 증거는 없다. 과거 ‘6상태’ 검증을 8상태로 소급한 것은 아니다.

이번 브라우저 확인: 애자일 선택→프로젝트 생성 표시→총괄 작업 공간, 이전의 정지미확인/이해미확인/양쪽확인 재개버튼 상태. [방법론 화면 캡처](../../assets/p01-methods-browser.png). 모든 버튼·전체 기능·사용자 검토 합격을 뜻하지 않는다.

보완본 브라우저 확인: 기본본 복사→노드 이름 편집/반영→검사 후 프로젝트 선택→주 작업 절차/우측 입력·산출 반영, 빈 방법론 적용 거부→노드 추가 후 필수값 누락 표시. [편집 화면 캡처](../../assets/p01-method-editor-browser.png).

추가 확인: 노드 이름 입력→다른 노드→원 노드에서 입력 유지. 문서 비교→충돌 차단(v1 유지)→재비교/반영(v2)→v1 원문 이력 보존. 인계 요청 뒤 수락 비활성→안전 요약 뒤 수락 활성. 손상 백업 영향 확인 비활성→정상 검증 뒤 영향 예시 표시. [문서 비교 캡처](../../assets/p01-document-comparison-browser.png), [430px 자료 탭 캡처](../../assets/p01-mobile-430-browser.png). `verify.cjs`는 위 탭 상태의 양성/차단 계약도 검사한다. 실제 계정 권한·백업 무결성·복구 성공을 검증한 것은 아니다.

미리보기 서버는 localhost 전용이며 제품 runtime과 분리. 검토 종료/중지 시 WORK_STATUS에 기록한 서버 세션만 종료하고 문서/시안은 보존한다. companion의 최신 파일이 제공되므로 뒤 버전에서 수정한 canonical HTML과 제공본 hash를 대조한다.

후속 브라우저 확인: v7의 노드 이동·필수 양식 연결·LLM 임무 표시, 4단계 생성의 목적 누락 차단→생성 뒤 준비 필요/실행 아님, 빈 산출물 부족→수동 작성 예시의 검토대기 보관/본문·출처 조회. 최종 v9는 새 탭에서 내장 N3의 AF02/AF03 기본 연결과 AF03 화면시안 작성 임무/필수 항목을 확인했다. [공간형 흐름도](../../assets/p01-spatial-flow-browser.png), [공식 양식](../../assets/p01-official-forms-browser.png). 전체 브라우저 재검사를 수행한 것은 아니다.

v10~13의 브라우저 핵심 확인과 현재 검토 hash는 REVIEW-02에 구분했다. 파일 선택/줄별 비교·입력 보호·이전/변경/모바일/클라이언트 차단을 확인했지만 실제 LLM·DB·provider 권한 검증은 아니다. 1MiB는 로컬 시안 안전 제한이며 제품 크기/파서·실제 백업/기간/설치 절차는 P02/P03 및 해당 제품 업무에서 확정한다.
