## 허용 범위와 제외

- 코드·화면·필요한 미적용 SQL·합성시험의 상세 기준으로 채택한다. 구체 구현 순서·허용 파일은 Main이 실제 의존성을 확인한 작업지시서로 고정한다.
- 실제 키 생성/조회·권한/ACL 변경·DB 접속/적용·서비스·컴파일·helper/OS·Agent 실행·실제 사용자 자료/백업 대상 조사는 제외한다. 기존 P03 R3 실행 제외도 유지한다.
- 실제 설치 provenance·build receipt·보호 공급자가 없는 동안 기본 거절을 유지한다. 합성 성공이나 임의 metadata/hash를 실제 신뢰·키 인가·배포 가능 근거로 표시하지 않는다.
