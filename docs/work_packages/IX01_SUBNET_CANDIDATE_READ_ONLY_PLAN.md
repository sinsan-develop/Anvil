# IX01 전용 IPv4 후보 산출을 위한 읽기 전용 관측안

상태는 **합성 검수 완료·실제 관측 미승인**이다. 판정 소스 `f9290ca3a2c9616a9e5a92535ef34f6c807a5ee6`와 `scripts/qa-ix01-subnet-candidate.ts` SHA256 `1CE97AB13FA4734F3306262FE4FC5F4AF514A1329D11D822F1A7CB83F1280110`을 고정한다. N2 후보와 비기본 경로의 충돌은 확인됐고, 허용 범위 전체가 점유됐는지는 미확인이다.

- **대상과 효과** — 지정 WSL-server의 동일 네트워크 namespace와 기존 Docker daemon이다. 승인 후 기존 strict SSH 연결 1회, 승인 후 30분 이내, 연결 내 관측 전체 최대 60초·개별 호출 최대 10초로 제한한다. 호스트의 기존 도구와 읽기 전용 명령만 사용한다. checkout, 임시 파일, 주소 예약, 외피, 망·컨테이너 생성 및 route·daemon 변경은 포함하지 않는다.
- **허용 입력** — WSL IPv4 주소와 인터페이스 prefix, 모든 IPv4 route table의 목적지/prefix와 table, Docker 네트워크 목록의 ID와 해당 네트워크의 IPv4 IPAM Subnet·IPRange·Gateway·AuxiliaryAddresses만 메모리에서 투영한다. ID는 IPAM 확인 및 같은 목록 대조에만 사용한다. 보존 네트워크가 전역 목록에 포함될 수 있어 **해당 네트워크의 위 IPAM 필드만 읽는 범위가 기존 보존 지시의 예외**다. 연결된 컨테이너 목록·inspect나 설정, 로그, 환경, 파일, DB와 Secret은 읽지 않는다.
- **완전성** — 같은 관측 안에서 Docker ID 목록을 앞뒤로 대조한다. 모든 table·인터페이스·IPv4 IPAM을 누락 없이 판독할 수 있어야 하며, IPv4/IPv6를 구별할 수 없거나 목록 변경·권한 오류·과다 응답·기한/도구 불명이 있으면 `UNKNOWN`으로 그친다. 원시 자료와 명령의 stderr는 수거·저장·표시하지 않는다. 호스트 메타데이터는 같은 namespace의 그 시점 관측이며 외부 VPN·Windows 경로나 미래 예약을 증명하지 않는다.
- **판정 및 반환** — 상위·하위 비기본 경로, 인터페이스 전체 prefix, 기존 Docker IPAM 전체를 배제한다. 고정 소스가 `CANDIDATE`와 새 /28 후보 하나만, 또는 `NO_CANDIDATE`·`UNKNOWN`을 반환한다. 이전 주소·경로·망 이름·ID는 출력하지 않는다. 실패·불명일 때 추가 조회·재시도는 하지 않는다.
- **후속 검증** — 후보를 얻어도 운영자 예약 근거와 실행 직전 비충돌 확인이 필요하다. 이 관측안은 N1·N2 또는 새로운 격리 시험을 실행할 권한을 주지 않는다. 전용 대역이 확인되면 기존 보호 조건을 유지한 새 격리 시험을 거쳐 TC01 저장·재조회 검증으로 복귀한다.
