# C-08 Invocation Prompt

이 WorkInstruction의 허용 경로와 완료 조건만 수행하라. 먼저 현재 branch/HEAD/status와 기존 repository_intelligence 계약을 확인하고, 한 명의 Developer Subagent write lease 범위 안에서 구현하라. 기존 public API와 no-write proof를 보존하면서 Python/TypeScript fixture용 symbol·dependency·test·impact 인덱스를 추가하고 deterministic JSON/hash 및 hostile-path 회귀 테스트를 작성하라. 테스트·compileall·diff check를 실행한 뒤 `COMPLETED`, `FAILURE_REPORT`, `INCOMPLETE`, `BLOCKED`, `CANCELLED` 중 하나로 결과를 보고하고, 완료 시 `docs/04_test_reports/C-08_COMPLETION_REPORT.md`를 작성하라. 범위 밖 파일과 운영 검증은 건드리지 말라.
