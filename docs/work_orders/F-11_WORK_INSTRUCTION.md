- SSRF 기준: [OWASP SSRF Prevention](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html). Endpoint는 운영자가 서버 측 환경 allowlist에 등록한 scheme·canonical host·port·IP 집합에만 허용한다. 사용자 URL의 path/query/fragment/userinfo, 중복/애매한 host 인코딩, 비표준 IP 표기를 거부하고 API path는 adapter가 생성한다. Metadata(IPv4/IPv6/hostname)·link-local·multicast·unspecified는 allowlist 여부와 무관하게 거부한다. Loopback/private는 해당 환경의 exact host:port:IP 허용 항목에만 예외적으로 허용한다. 모든 A/AAAA 결과를 검사하고, 혼합 허용/비허용 응답·불일치·DNS rebinding은 송신 전 거부한다.
