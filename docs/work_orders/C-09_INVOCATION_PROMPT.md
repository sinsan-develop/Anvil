# C-09 Invocation Prompt

WorkInstruction 범위만 수행하라. 기존 경로/실행 계약을 먼저 읽고, Git·Docker·WSL 실제 외부 상태에 접근하지 않는 deterministic 표준 라이브러리 구현과 fixture 회귀 테스트를 작성하라. canonical path identity와 read-only Tool Gateway가 fail-closed인지 확인하고 완료보고서에 기준선, 변경, 정확한 검증 명령/결과, 오류·미검증 범위·rollback을 기록하라. 결과 상태는 COMPLETED/FAILURE_REPORT/INCOMPLETE/BLOCKED/CANCELLED 중 하나로 보고하라.
